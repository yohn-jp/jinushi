# Security Policy

## Supported versions

Security fixes target `main` and the latest published release. This project does not currently maintain long-term-support branches.

## Reporting a vulnerability

Report suspected vulnerabilities privately through this repository's GitHub Security Advisories rather than a public Issue.

Include the affected version or commit, impact, and a minimal safe reproduction where possible. Do not include credentials, private keys, authorization headers, tokens, or other sensitive material in public evidence.

If private reporting is unavailable, open an Issue containing only nonsensitive information and ask a maintainer to establish a private channel.
